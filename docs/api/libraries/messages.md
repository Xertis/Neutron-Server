> [!WARNING]
> `pack` и `event` **должны быть одинаковыми в коде сервера и клиента** для одного и того же сообщения — именно по ним `api.events` сопоставляет отправителя и обработчик.

`Message` — обёртка над `api.events`, которая берёт на себя кодирование и декодирование данных сообщения по заданной схеме. Вместо ручной упаковки байт в `events.tell`/`events.send`/`events.on` каждое сообщение описывает структуру одного типа данных один раз, а дальше отправляет и принимает уже готовые Lua-таблицы.

## Создание сообщения

```lua
Message.new(pack: string, event: string, schema: table) -> Message
```

```lua
local PingMessage = Message.new("mypack", "ping", {
    id = "string",
    data = "array"
})
```

- `pack` — имя пака, внутри которого находится сообщение.
- `event` — строковый идентификатор сообщения внутри пака.

## Схема сообщения

Схема — обычная таблица `{ ключ = тип }`. Порядок полей при кодировании фиксируется один раз при вызове `Message.new` одинаковым образом для сервера и клиента.

```lua
local MoveMessage = Message.new("move", {
    x = "float32",
    y = "float32",
    z = "float32"
})
```

Поля можно вкладывать друг в друга — значением указывается вложенная схема (таблица), а не строка-тип:

```lua
local SpawnMessage = Message.new("mypack", "spawn", {
    name = "string",
    pos = { x = "float32", y = "float32", z = "float32" }
})
```

При отправке/получении такого сообщения данные выглядят как обычная вложенная таблица: `data.pos.x`, `data.name` и т.д.

## Доступные типы

| Тип | Размер | Описание |
|-----|--------|----------|
| `boolean` | 1 бит | Логическое значение |
| `uint8` | 1 байт | Целое без знака, 0..255 |
| `int8` | 1 байт | Целое со знаком, -127..127 |
| `uint16` | 2 байта | Целое без знака, 0..65535 |
| `int16` | 2 байта | Целое со знаком |
| `uint24` | 3 байта | Целое без знака, 0..16777215 |
| `int32` | 4 байта | Целое со знаком |
| `uint32` | 4 байта | Целое без знака |
| `int64` | 8 байт | Целое со знаком |
| `float32` | 4 байта | Число с плавающей точкой одинарной точности |
| `float64` | 8 байт | Число с плавающей точкой двойной точности |
| `var` | переменный | Целое без знака, компактная кодировка до 8 байт |
| `hex` | 4 бита | Одна hex-цифра (0-15) |
| `norm8` | 1 байт | Нормализованное значение -1.0..1.0, упакованное в байт |
| `string` | переменный | Строка переменной длины |
| `bytearray` | переменный | Произвольный массив байт переменной длины |
| `bson` | переменный | Произвольная структура, сериализованная как BSON |

### Generic-обёртки

| Тип | Описание |
|-----|----------|
| `Array<T>` | Список элементов типа `T` переменной длины |
| `Nilable<T>` | Опциональное значение типа `T` |
| `Pair<T, U>` | Хранит ровно два элемента произвольных типов |
| `Triple<T, U, V>` | Хранит ровно три элемента произвольных типов |
| `Vec2<T>` | Вектор из двух значений типа `T` |
| `Vec3<T>` | Вектор из трёх значений типа `T` |

> [!NOTE]
> Допускаются вложенные конструкции вида `Vec2<Nilable<uint8>>`.

## Отправка сообщений

### Сервер

```lua
-- Отправляет данные указанному клиенту
Message:tell(client: Client, data: table)
PingMessage:tell(client, { id = "abc", data = {1, 2, 3} })

-- Отправляет данные всем подключённым клиентам
Message:echo(data: table)
PingMessage:echo({ id = "abc", data = {1, 2, 3} })

-- Отправляет данные только тем клиентам, для которых selector вернул true
Message:selective_echo(data: table, selector: function(client): boolean)
PingMessage:selective_echo({ id = "abc", data = {1, 2, 3} }, function(client) return client.active end)
```

### Клиент

```lua
-- Отправляет данные на сервер
Message:send(data: table)
PingMessage:send({ id = "abc", data = {1, 2, 3} })
```

`data` — таблица в виде, описанном схемой сообщения. Кодирование в байты и вызов `events` происходят внутри метода.

## Обработка сообщений

### Сервер

```lua
Message:on(handler: function(client: Client, data: table))
PingMessage:on(function(client, data)
    print(data.id, #data.data)
end)
```

### Клиент

```lua
Message:on(handler: function(data: table))
PingMessage:on(function(data)
    print(data.id, #data.data)
end)
```

В `handler` приходят не байты, а уже декодированная таблица `data` — весь разбор по схеме делает само сообщение перед вызовом обработчика.
