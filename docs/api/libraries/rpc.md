Система **rpc** является обёрткой над **events**, предоставляющей удобный способ сериализации и десериализации данных во время отправки.

---

## Сервер

### Методы отправки

```lua
-- Возвращает функцию, которая отправляет данные клиенту в формате bson
api.rpc.emitter.create_tell(pack: string, event: string) -> function(client: Client, ...)

-- Идентичен create_tell, но отправляет данные ВСЕМ клиентам
api.rpc.emitter.create_echo(pack: string, event: string) -> function(...)
```

### Методы чтения

```lua
-- Регистрирует обработчик на ивент пака
-- В отличие от events.on, в обработчик поступает десериализованный bson
api.rpc.handler.on(pack: string, event: string, handler: function(client, ...))
```

## Клиент

### Методы отправки

```lua
-- Возвращает функцию, которая отправляет данные серверу в формате bson
api.rpc.emitter.create_send(pack: string, event: string) -> function(...)
```

### Методы чтения

```lua
-- Регистрирует обработчик на ивент пака
-- В отличие от events.on, в обработчик поступает десериализованный bson из полученных байт
api.rpc.handler.on(pack: string, event: string, handler: function(...))
```
