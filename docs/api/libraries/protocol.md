## Структура модуля

Модуль содержит:
- `ServerMsg` — типы пакетов, отправляемые сервером.

Ознакомиться со структурой пакетов можно в файле:
```
server:resources/protocol/annotation_server.yaml
```

## Основные методы

```lua
-- Отправляет пакет указанному клиенту
protocol.tell(client, packet_type, data)

-- Отправляет пакет всем клиентам
protocol.echo(packet_type, data)
```

**Параметры:**

| Параметр | Тип | Описание |
|----------|-----|----------|
| `client` | `Client` | Объект клиента. |
| `packet_type` | `string` | Тип пакета из `ServerMsg`. |
| `data` | `table` | Данные пакета. |

**Пример:**

```lua
protocol.tell(client, Protocol.ServerMsg.PlayerHandSlot, {
    slot = 0
})
```

## Важные примечания

1. Данные пакета почти не валидируются перед отправкой.
2. Данные пакета будут пропущены через интерцепторы.
