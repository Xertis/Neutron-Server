## Сервер

Создаёт прокси-таблицу с автоматической синхронизацией данных при изменении значений между сервером и клиентами.

- Может хранить только пары ключ–значение.
- Допустимые типы значений: `string`, `number`, `nil`, `bool`.

### Публичные окружения

```lua
api.env.public.create(pack: string, env_name: string) -> Proxy-table
```

Создаёт публичную прокси-таблицу, доступ к которой имеют все клиенты.

### Приватные окружения

```lua
api.env.private.create(pack: string, env_name: string, client: Client) -> Proxy-table
```

Создаёт приватную прокси-таблицу, доступ к которой есть только у одного клиента.

---

## Клиент

На клиенте `api.env` предоставляет доступ к синхронизированным окружениям, созданным на сервере. Изменения значений на сервере автоматически отражаются на клиенте.
