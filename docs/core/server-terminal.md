# Терминал сервера

## Команды терминала

```bash
chat "сообщение" -> Выводит сообщение в чат от лица root
stop -> Выключает сервер
```

## Логи сервера

Логи сервера в терминале стараются соответствовать стилю VoxelCore, но имеют свои отличия.

### Примеры логов

**Лог движка:**
```lua
[I] 2026/08/13 19:16:02.763+0300 [           lua-debug] cleaning scripts cache
```

**Лог ядра:**
```lua
[I] 2026/08/13 19:15:36.437+0300 [            run/main] world loop is started
```

### Ключевые различия

1. **Идентификатор источника:**
   - В движке в `[]` указывается компонент движка, отвечающий за лог.
   - В ядре в `[]` указывается частичный путь к скрипту, где был вызван лог.

2. **Типы сообщений:**

```lua
[I] - информация
[T] - тестирование
[W] - предупреждение
[E] - ошибка
[P] - паника ядра
```

### Особенности уровней ошибок

- `E` (ошибка) — чаще всего не критична, сервер продолжает работу.
- `P` (паника) — критическая ошибка. Сервер попытается продолжить работу, но даже если сервер продолжает работать после паники, рекомендуется:
  1. Дождаться сохранения данных.
  2. Перезагрузить сервер.
